## What this does and does not establish

It establishes that at `af0caf7`, from published bytes alone, on three
interpreters, every number the README states is reproducible by someone with no
access to the author's machine.

It does not establish the multi-operating-system half of the portability claim.
These runs are Windows-only. The Linux and macOS evidence is the hosted receipt
set under `portability/receipts/hosted/`, which is pinned and mechanically
re-checkable — `verify_receipts.py` covers it — but historical: it was produced
in the `6ad8b21` era, not at this commit. No current hosted run exists at this
commit, because `.github/workflows/robustness-verification.yml` triggers on a
branch that no longer exists and `portability.yml` triggers only on `main`. That
gap is row A2 of [ADOPTION.md](../ADOPTION.md).

It also does not establish anything a clone cannot reach: this commit is six
commits ahead of `origin/main`, so a third party cloning the published default
branch today gets a different artifact than the one measured here. That is row
A1.
