# F-WP1-016 — Contradictory commit testimony could reach SCOPE READY

Source: Deep Security Scan finding `csf_957857a5bf3fa6802da7c89b` (low).

The SCOPE assessor type-checked `result_commit_named` and `commit_found`
independently but did not bind either Boolean to `native.result_commit`. A
found commit that was never named, a named commit with no identity, or an
identity paired with `result_commit_named=false` could therefore reach READY.

Repair: a named result requires a bounded nonempty exact identity; an unnamed
result requires a null/absent identity; and `commit_found=true` requires that a
result was named. These contradictions are rejected before missing-content
abstention. The calibration law is otherwise unchanged: coherent
`named=false/found=false/changed_paths=null` testimony remains sufficient, and
changed paths remain required only when the named commit was found. Regression:
`FailClosedBoundaryTests.test_scope_commit_identity_and_lookup_testimony_are_coherent`.
