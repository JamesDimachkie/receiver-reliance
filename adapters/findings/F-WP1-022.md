# F-WP1-022 — Portable runtime imports were ambient or undeclared

Source: Deep Security Scan finding `csf_a49d6e27b949354eeeb452cb` (medium).

`portable/cli.py` added repository directories to `sys.path` and used bare
imports. An undeclared same-name module could precede the intended verifier,
preflight, decision implementation, batch dependency, or sidecar dependency;
the manifest verifier did not reject filesystem extras.

Repair: CLI bootstrap authenticates the bounded manifest index, then every
repository module is looked up by an exact manifest path, bounded-read and
SHA-256 authenticated, compiled from those verified bytes, and executed under
a private name. Sidecar dependencies are supplied as temporary authenticated
aliases and `sys.path` is restored after legacy module initialization.
Undeclared paths are rejected before filesystem use; ambient project modules
are never selected. Regression:
`PortableCliHardeningTests.test_undeclared_and_ambient_project_modules_are_not_importable`
and `test_all_runtime_modes_load_declared_repository_bytes`.
