# F-WP1-018 — Direct objects had no total-node ceiling before serialization

Source: Deep Security Scan finding `csf_6047125f4efab39f34e04fcd` (low).

The direct `preflight()` API limited depth and the width of each individual
container but not aggregate graph size. A broad bounded-depth object could be
fully traversed and handed to `json.dumps` before the serialized-byte ceiling
was checked.

Repair: the bounded JSON walk now admits at most 4,096 visited nodes across the
whole direct object. The walk fails before canonical serialization, so an
over-limit graph returns `PREFLIGHT_JSON_DOMAIN_INVALID` without allocating
the canonical JSON byte string. Regression:
`FailClosedBoundaryTests.test_direct_objects_have_a_total_node_bound_before_serialization`.
