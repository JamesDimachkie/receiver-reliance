# F-WP1-003 — Plain mappings could bypass preflight

Historical general-adapter finding. F-WP1-009 later stood the capability and
request-builder surface down; neither is exported by the fallback.

Status: repaired in code.

The old request builder accepted any profile-shaped mapping, so preflight was
advisory.

Repair: `build_engine_request` accepts only a registry-backed opaque
`ValidatedProfile` capability. Only successful fresh preflight
mints it; the builder rejects mappings and forged dataclass instances. The
capability stores sealed canonical profile bytes, exposes only detached
copies, and is checked against an independent weak registry seal before every
build. The builder also repeats deterministic derivation from the fresh atomic
snapshot, so changing both an object's bytes and its visible digest cannot
replace the registry-backed profile.
Regressions: `Finding003CapabilityTests`.
