# F-WP1-017 — Unhashable family values escaped the three-state boundary

Source: Deep Security Scan finding `csf_00b1db54a2499397d0a96626` (medium).

A bounded JSON array or object was legal at `/family` until `_check_record`
used it as a mapping key. The resulting `TypeError` escaped direct preflight
and JSONL processing and prevented later rows from receiving results.

Repair: family is proven to be a string before every mapping membership or
lookup. Non-string JSON family shapes now receive `PREFLIGHT_FAMILY_INVALID`,
and JSONL continues with subsequent rows. The stream parser also contains
residual `TypeError` as a deterministic per-line invalid result. Regression:
`FailClosedBoundaryTests.test_family_type_is_validated_before_mapping_lookup`.
