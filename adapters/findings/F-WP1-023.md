# F-WP1-023 — Unsupported interpreters could be reported READY and execute

Source: Deep Security Scan finding `csf_e887fc0581a500716dd23b81` (medium).

The bundle manifest declared CPython 3.12, 3.13, and 3.14, but CLI verification,
doctor status, and runtime modes did not compare that declaration with the
active interpreter. Unsupported implementations or versions could therefore
report READY and execute outside the portability contract.

Repair: verification now combines bundle failures with an active-runtime
admission check. Only CPython 3.12, 3.13, or 3.14 is admitted; `verify` fails,
`doctor` reports `NOT_READY`, and preflight/decide/sidecar stop with startup
status 70 on every other runtime. Regression:
`PortableCliHardeningTests.test_unsupported_interpreters_are_not_admitted`.
