# F-WP1-005 — Single-receipt comparison did not prove effect completeness

Historical general-adapter finding. F-WP1-009 later stood the effect surface
down; it is not part of the portable fallback.

Status: repaired with a narrowed, explicit boundary.

The old Boolean helper could validate one supplied preimage while ignoring
missing, duplicate, or additional expected effects.

Repair: `reconcile_effect_log` takes the complete caller-declared expected ID
set, complete normalized observed log, and one closed receipt expectation per
ID. It rejects subset/cardinality, duplicate, ID, digest, receipt, and preimage
binding mismatches. An additive host binding digest covers the exact effect ID,
observed digest, engine receipt, and complete preimage digest, so evidence
cannot be relabeled under another effect ID even when effect bytes match. It
does not claim to discover effects outside the host's
declared observation boundary. Regressions: `Finding005EffectTests`.
