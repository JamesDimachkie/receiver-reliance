# F-WP1-004 — Transcript “verification” did not verify semantics

Historical general-adapter finding. F-WP1-009 later stood the transcript
surface down; it is not part of the portable fallback.

Status: repaired in code.

The old helper checked only local digests and did not parse/correlate the
response or validate its semantic derivation.

Repair: the surface is now `validate_transcript_entry`. It requires the exact
`RR-HOST-CORE-TRANSCRIPT-2`, core request, and runner response literals;
canonical wire objects; correlated IDs; decision-input binding; then exact
frozen-core re-execution in an isolated interpreter with byte-identical
response and exit code. This prevents a cached `pcb_runner` module substitute
from becoming the evaluator. The
re-execution covers accepted schemas, response sealing, and derivation.
Regressions: `Finding004TranscriptTests`.
