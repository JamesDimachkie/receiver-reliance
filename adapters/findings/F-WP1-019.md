# F-WP1-019 — Malformed task status asserted INTENDED_USE

Source: Deep Security Scan finding `csf_b9b0bb95309b8905457dab84` (low).

SCOPE appended `INTENDED_USE` whenever `native.status` was non-null. Booleans,
integers, containers, and an empty string could therefore create a semantic
declaration while the row remained READY.

Repair: a supplied status must be an opaque bounded nonempty string before it
can assert `INTENDED_USE`; malformed values are
`PREFLIGHT_SCOPE_STATUS_INVALID`. Omitted/null status still makes no intended-
use declaration, and the existing corpus's nonempty task-status strings retain
their calibrated behavior. Regression:
`FailClosedBoundaryTests.test_scope_status_must_be_a_bounded_nonempty_string`.
