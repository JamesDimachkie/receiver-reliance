# F-WP1-001 — Event count was not acknowledgment evidence

Historical general-adapter finding. F-WP1-009 later stood that surface down;
only the portable contradiction/applicability checks are shipping.

Status: repaired in code; current corpus exposes an evidence boundary.

The first adapter treated the terminal timestamp of any multi-event lifecycle
as acknowledgment. That silently invented the native concept whose absence E7
was meant to expose.

Repair: OBL-17 now requires closed typed events with exactly one `EFFECTIVE`
and one terminal `ACKNOWLEDGMENT`, unique sequences, and acknowledgment
strictly later in both sequence and time. Any terminal predecessor is taken
from the observed immediately preceding event. Untyped or contradictory rows
refuse H4. Regression: `Finding001LifecycleTests`.
