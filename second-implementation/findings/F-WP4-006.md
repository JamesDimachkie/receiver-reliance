# F-WP4-006 — authority bytes were parsed before custody verification

Status: valid, fixed after fresh refuter attempt 2, and provenance-corrected by
final Path A author attempt 3. Official author strike remains 2.

## Primary contract evidence

The supplemental contract's `content_addressed_schema_resolver` requires
packet/projection URIs to resolve only after exact byte-length and raw-SHA-256
verification, with `unlisted_or_digest_mismatch` set to `FAIL_CLOSED`. Its
accepted-0.2 generation pins bind the primary contract, and its resolver pins
bind the packet and projection. The public supplemental acceptance chain
supplies the external final supplemental-contract digest.

The verifiable runtime bindings are:

- primary contract: 321451 bytes,
  `DCFCB0714E1A7E677548057987F604D227F791F3FC3E0EA89BE5ED932447F48E`;
- supplemental contract: externally accepted raw SHA-256
  `6B2CAD02DDE7388D63D66E4863E5233CFBD1DC413575D9D260DB9799C7023A12`;
- sanitized packet: 513384 bytes,
  `73A4FF4DD8ABA41D0F68414CB754EFCDF9807FAE73354F1959420B16C5F359F3`;
- shared projection: 19051 bytes,
  `1449369AE3CC4458F3F904ADCF0F24B0685E86C65EAC2AE656F7A3E4AD946460`.

The external receipt does not declare a supplemental-contract byte length.
The earlier repair recorded its observed length as though it were an
authority pin. Attempt 3 removes that unverifiable claim instead of inventing
one.

## Repair

`Contracts` first verifies the supplemental contract's raw SHA-256 against the
external receipt binding and only then parses those bytes. The authenticated
supplemental contract supplies the primary contract's declared length/hash and
the resolver's packet/projection declared lengths/hashes. Each of those three
files is verified before its JSON is decoded or admitted to resolution. Any
mismatch raises a deterministic authority-pin failure.

The local gate copies all four authorities into an isolated system temporary
directory, proves the intact set loads, applies a same-length byte mutation to
each file one at a time, and proves all four mutations fail closed on SHA-256
before the mutated JSON is parsed. The artifact verifier separately proves the
runtime reads exactly those four authorities and that every derived pin still
matches the authenticated declarations.
