# F-WP4-004 — host integer guard escaped as `ERR_INTERNAL`

Status: fixed after fresh refuter attempt 2 and rebound by final Path A author
attempt 3. Severity: CRITICAL. Official author strike: 2.

## Evidence

The fresh refuter supplied `b"1" * 4301 + b"\n"` (SHA-256
`6B5B3FCE817A98A42EB47E0206710ED2329BA33EC74743219EA2599E62CC7B4D`).
The frozen black box returned exit 2, empty stderr, and sealed `ERR_NUMBER`
stdout SHA-256
`DD26E054DFC5F888F85E0C0323249B392F859292D047B923DB6343FF4E66C66F`.
The candidate API and CLI instead contained Python's integer-conversion guard
as sealed `ERR_INTERNAL`. The 4300-digit LF neighbor agreed before the guard;
without the LF, 4301 digits must select `ERR_JSON` before `ERR_NUMBER`.

## Cause and repair

The number lexer called `int(token)` before deciding whether an integer was
outside the safe range. Python 3.12 limits decimal conversion digit counts, so
the host guard—not the contract—selected the result. The repaired lexer checks
the sign, digit length, and lexicographic magnitude against
`9007199254740991` before conversion. Out-of-range integers and every valid
fraction/exponent spelling receive a harmless internal placeholder plus their
error pointer; only safe integers reach `int()`. `Decimal` conversion was
removed too.

The final bounded set executes 84 numeric shapes. At each of 4,299, 4,300,
4,301, 10,000, 100,000, and 1,000,000 digits it covers positive and negative
integers with and without LF, integer and fractional mantissas, positive and
negative exponents, exponent framing, positive and negative leading zeroes,
and array/object pointers. Frozen black box, candidate API, and isolated
candidate CLI agree byte-for-byte on every case. An independent gate with
`int_max_str_digits=640` exercises the same set.
