# F-WP4-011 — recursion, authority bootstrap, and wrapper CLI gaps escaped the total boundary

Status: fixed in hardening wave W4. Deep-scan findings

## Evidence

`NOT_ACYCLIC` used one Python call per graph depth and therefore varied with
the embedding process's recursion limit. The module-level `execute` obtained
the lazy implementation before entering `Implementation.execute_bytes`, so a
missing, malformed, unreadable, or digest-mismatched authority escaped as a
host exception. Finally, the Python API exposed wrapper execution while the
CLI sent every wire object to the semantic request path.

## Repair

A Kahn-style iterative traversal now determines acyclicity with no dependency
on the host recursion limit. Authority files are opened as non-link regular
handles, stat-bounded before reading, and the lazy bootstrap now sits inside
the raw ABI's deterministic response boundary. The CLI exposes an explicit
`execute-wrapper` route and its established `execute` route recognizes the
canonical wrapper format, dispatching through the same strict bounded decoder
and `execute_wrapper` implementation used by the API.

Authority failure remains fail closed. The total response intentionally does
not reveal which path, digest, or parse failed.
