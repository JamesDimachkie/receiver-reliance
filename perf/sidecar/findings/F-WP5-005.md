# F-WP5-005 — no-replay evidence was asserted, not counted

## Finding

The timeout test observed an exception but did not prove how many times the
client wrote or the child accepted the request. Receipt command metadata also
omitted the actual `--receipt` invocation.

## Correction

The supervisor exposes monotonic request-attempt, completed-write, response,
and automatic-replay counts. The timeout child appends one marker only after
reading the request, then stalls. Receipt command metadata records
`sys.orig_argv`, including the actual receipt path.

## Regression evidence

The admitted attempt-8 sidecar receipt records one child acceptance, one
attempt, one completed write, zero responses, and zero automatic replays,
followed by child termination. The verifier enforces those values, the actual
`sys.orig_argv`, and the immutable receipt path.
