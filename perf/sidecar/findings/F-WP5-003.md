# F-WP5-003 — EOF before response left a live child running

## Finding

On stdout EOF before a response, the supervisor raised but did not terminate a
child that had closed stdout and continued running.

## Correction

EOF before the one expected response now follows the ambiguous-outcome path:
terminate, escalate to kill if needed, wait, then raise.

## Regression evidence

A temporary child reads one request, closes file descriptor 1, and sleeps.
The supervisor rejects EOF and proves the child has stopped before returning.
